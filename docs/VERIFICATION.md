## 真实 OCI 只读核验

通过当前应用的官方 SDK 适配层，在一个已有授权账号的单一区域完成以下检查。凭据仅在本机内存使用，没有导入演示数据库、写入仓库或保存原始资源响应。临时核验脚本在 SDK 调用边界仅允许列举和读取操作。

- 账号和区域验证成功。
- 资源清单返回 1 个实例、1 张网卡、2 个私网地址、2 个公网地址和 1 个启动卷，无同步告警。
- Reserved 公网地址被正确标为受保护。
- 读取 NSG 和安全列表成功，安全列表返回 ETag。
- 读取创建选项成功，包括可用域、规格、镜像、子网。
- 原生流量指标返回 60 个数据点；该实例 CPU 指标无数据，保留缺失状态。
- 25 个 SDK 客户端全部关闭，云写请求为 0。

资源刷新改动在本地真实模式另外验证：浏览器打开实例列表后，两个现有账号分别完成一次自动同步，页面显示新的同步结果；这些自动任务没有进入普通任务历史。检查同时覆盖精简后的桌面、390px 窄屏和任务表。只允许自动库存刷新请求，其执行内容为读取 OCI；未提交实例、网络或存储变更。

## 真实 OCI VNC 验收

使用已授权的新加坡实例，在当前真实模式的本地单容器部署上，由浏览器点击连接完成验收。测试只创建临时 OCI 实例控制台连接，没有使用来宾系统账号登录，也没有发送 Ctrl+Alt+Del 或系统命令。

- 真正的 noVNC 客户端完成 RFB 握手，显示 1280×800 的 Ubuntu 26.04.1 LTS `tty1` 登录界面。
- 适应窗口、切换全屏、退出全屏和主动断开通过；无浏览器运行错误。
- 主动断开后会话关闭并释放占用；临时 SSH 密钥目录删除。
- 实云联调修复了区域服务使用 ECDSA 主机密钥、内层服务仅允许一个活动连接，以及控制台读取 API 不保证 ETag 的兼容问题。
- 失败尝试与成功尝试均清理本应用创建的临时连接；保留正常会话历史用于核对，不删除其他客户端的控制台连接。

此结果验证浏览器到 OCI 的控制台通道与画面，未验证来宾系统密码登录。VNC 显示的是实例本身的显示输出；没有桌面环境的 Linux 服务器通常显示文本登录界面。

## 复跑

```sh
npm ci
npm run typecheck
npm test
npm run build
# 先构建本地镜像，再验证隔离容器生命周期。
docker compose build app
npm run test:runtime
```

本地演示环境浏览器验证：

```sh
node scripts/bootstrap.mjs
docker compose up -d --build --wait --wait-timeout 60
npx playwright install chromium
node --env-file=.env node_modules/@playwright/test/cli.js test
```

Windows 默认使用已安装的 Edge；其他平台默认 Chromium，可通过 E2E_BROWSER_CHANNEL 指定浏览器通道。E2E_BASE_URL 仅接受本机源地址。ADMIN_PASSWORD 从环境注入，不能提交到代码。需要演示截图时设置 E2E_SCREENSHOTS=1，输出在已忽略的 test-results/。

CI 使用 GitHub Ubuntu runner 预装的 Chrome，执行类型检查、离线测试、生产构建、Compose 单服务启动、隔离容器故障验证和同一套浏览器回归；不额外下载 Chromium。执行记录在仓库 Actions 页面。

## 验收边界

**实例与网络等资源变更未执行真实写操作验收**：本次没有为测试而创建、停止、重启、终止实例，也没有实际轮换 IP、修改磁盘或安全规则。上述功能具备正式 SDK 实现与离线回归覆盖，真实写入仍需在指定的隔离资源上验收。临时 OCI 控制台连接的创建与删除单独记录，不等同于这些资源操作已通过实云验收。

容器重启持久化已经验证；完整备份归档及异机恢复演练尚未执行。主密钥与数据库备份规则见 [运维说明](OPERATIONS.md)。应用健康检查不代表所有 OCI 权限、区域或指标均可用。
