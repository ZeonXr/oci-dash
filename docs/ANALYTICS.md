# 流量、费用与 CPU 统计

统计读取使用官方 OCI API，不修改云资源，也不在实例中安装采集代理。响应的 `source` 固定为 `oci`。未保存账号时返回空报告，不读取凭据、不请求 OCI，也不补充示例数据；`source` 表示数据渠道，不表示本次一定发出了云请求。

## 接口与范围

三个接口都要求登录。同路径 `POST` 使用相同 URL 查询参数请求刷新，并要求同源；不接收任意 MQL、租户 ID 或凭据。短时间重复刷新可以合并执行或复用刚生成的结果。

| 接口                     | 查询参数                                                                             | 范围                                                     |
| ------------------------ | ------------------------------------------------------------------------------------ | -------------------------------------------------------- |
| `/api/analytics/traffic` | `accountId`、`region`、`instanceId`、`vnicId`、`startDate`、`endDate`、`granularity` | 最近 90 个 UTC 日；`hourly` 或 `daily`                   |
| `/api/analytics/costs`   | `accountId`、`region`、`service`、`startDate`、`endDate`、`granularity`              | `daily` 最多 90 日；`monthly` 最多 12 个已结束的完整月份 |
| `/api/analytics/cpu`     | 仅可选 `accountId`                                                                   | 固定为最近 24 个完整 UTC 小时                            |

日期使用 `YYYY-MM-DD`，包含首尾日；服务端转换为起点包含、终点不包含的 UTC 时间区间。费用月查询必须从月初开始、在月末结束，不包含尚未结束的月份。

总览的“近 7 日”和“近 30 日”不包含今天，“本月”包含今天已完成的流量小时。CPU 窗口独立于总览日期筛选。界面跨 UTC 日期或月份后重新计算预设范围。

流量与成本页的相对日期预设在跨 UTC 日界、恢复页面可见以及手动刷新时重算；自定义日期始终保持用户选择的范围。费用的月粒度预设仍只包含已结束的完整月份。

公共响应类型位于 [analytics-contracts.ts](../src/lib/analytics-contracts.ts) 和 [cpu-contracts.ts](../src/lib/cpu-contracts.ts)。`generatedAt` 表示查询生成时间，不等于所有数据已上报完整。

## 流量

- 来源为 `oci_vcn/VnicFromNetworkBytes`（接收）和 `VnicToNetworkBytes`（发送）。使用 `1h.sum()`、`resolution=1h` 读取完整小时，再聚合为 UTC 日。
- OCI 聚合时间戳表示窗口结束，响应中的时间戳表示窗口开始。尚未结束的小时不计入，`dataThrough` 标明截止边界。
- 统计范围是当前库存中的网卡及账号当前启用区域。已移除的历史网卡不在查询内；同一网卡的多个 IP 无法分别计量。
- 包含内网通信，不能直接用作公网账单或代理用户计量。API 保留字节值，界面使用 GiB。
- 缺失数据为 `null`。部分网卡或时间窗口缺失时显示已观测小计，并标记不完整；整个桶缺失时不补零，不跨缺口连线。

流量摘要、趋势与实例排行使用同一查询范围。实例排行合并该实例的当前网卡；“完整”仅描述本次查询的覆盖情况，不证明原始分钟数据或历史网卡全部齐全。

## 费用

费用按租户查询 Usage API 的 `COST`，以币种、服务、区域和资源 ID 分组。服务端会避免旧重复租户配置造成重复累计。连接服务的区域使用账号配置，费用行的 `region` 则是费用所属区域。

- 金额以十进制字符串汇总，不同币种不相加；不默认 USD。
- 缺失金额、缺失币种、空结果和真实零费用分别处理。无法确认完整性时不生成完整总额。
- 分页标记重复、数据上限、无效记录和账号读取失败均可使结果变为部分数据。
- 当前库存外的费用项目仍保留；能够关联到实例、启动卷或网卡的项目会补充名称。
- 最近两日可能继续补报，当前金额不是最终账单承诺。服务或区域筛选后的金额是对应范围的小计。
- 服务明细缺失时不补零，也不按总额推算堆叠分布。SDK 已将原始数字解码为浮点数时，应用无法恢复已经丢失的源精度。

成本读取需要相应的 Usage API 权限，例如 `read usage-report in tenancy`。其他资源的读取权限不保证能够读取费用。

## CPU

来源为 `oci_computeagent/CpuUtilization[5m].mean()`。每个实例保留 24 个完整 UTC 小时，每小时最多有 12 个五分钟均值样本。

- 单个热图格子是该小时有效样本的平均值；记录实际样本数和覆盖状态。
- 实例平均值对有数据的小时等权平均；实例峰值是最高的小时均值，不是瞬时峰值。
- 总体每小时对有数据的实例等权平均，摘要再对这些有效小时等权平均，与缩略图口径一致。
- 无样本保留 `null`，与实际 0% 区分。实例生命周期状态来自库存，不是连通性检测结果。
- 依赖实例已有监控代理及 OCI Monitoring 权限；没有数据不代表实例离线。

CPU 实际 RPC 并发上限为 2，整体期限为 20 秒，最多查询 20 个账号、200 个库存实例。超时返回已取得的部分结果，缺失实例不补零。

## 实例监控

实例详情的 `/api/instances/:id/metrics` 与总览 CPU 热图是不同查询。支持最近 `1h`、`24h`、`7d`，对应 60、300、3600 秒的聚合区间，响应的 `intervalSeconds` 明确该区间。CPU 使用区间均值；网络使用各当前网卡的收发字节总量。

摘要卡片分别选择 CPU、接收和发送最新的有效采样，并显示各自的采样时间。网络平均速率按 `字节 × 8 ÷ intervalSeconds ÷ 1,000,000` 换算为 Mbps，不代表瞬时带宽；不同指标的最新采样时间可能不同。库存中没有监控采样时不填入假值，缺失与实际零值保持区分。

同范围的并发查询共享执行，缓存有效期为 60 秒。整体等待期限为 20 秒，实际 RPC 并发上限为 4；超时返回明确错误，页面保留上次结果。最后一个调用者离开时取消查询，已经派发的 RPC 真正结束后才释放并发槽和客户端。账号凭据、区域或实例归属变化后，不复用旧范围的结果。

## 缓存、取消和一致性

| 数据 | 正常有效期 | 存放位置      |
| ---- | ---------- | ------------- |
| 流量 | 5 分钟     | 内存及 SQLite |
| 费用 | 1 小时     | 内存及 SQLite |
| CPU  | 60 秒      | 内存          |

部分结果使用更短的有效期。流量和费用缓存最多 32 份，报告内容合计最多 16 MiB，单份最多 4 MiB。持久缓存不延长原 TTL；损坏、过期或存储不可用时重新查询，写缓存失败不会丢弃新结果。这些缓存不是长期历史归档。

缓存按账号身份、凭据版本、启用范围和查询参数隔离。读取前后检查账号配置；单实例指标也在缓存命中前检查当前区域。缓存不保存 API 私钥或登录凭据。

流量和费用跨账号查询有 50 秒总期限、最多两个账号读取；单账号读取另有 45 秒限制。到期后停止派发，保留已完成账号并标记未完成范围。相同请求共享执行；仅当所有调用者都离开时取消共享查询。

CPU 查询同样接收调用者取消信号；切换账号或离开页面后，不再为无人等待的查询派发新读取。多个页面共享同一查询时，一个调用者离开不会取消其他调用者；实际 RPC 结束后才释放并发槽。

总览按缓存期限自动读取，页面隐藏或离线时暂停定时查询。失败时保留旧结果并退避一分钟；已经过期的响应至少间隔 30 秒再查，避免客户端时钟偏差造成密集请求。
