# 流量统计与成本分析

两个页面均按需查询，先使用应用内短期缓存；点击“刷新”重新读取 OCI，重复的并发查询合并。不会修改云资源，也不在服务器安装采集代理。第一版不包含长期历史归档、预算、预测、credits 或按代理用户计量。

一次跨账号查询最多执行 50 秒，账号读取并发上限为 2；单账号读取仍有 45 秒限制。达到整体期限后停止派发剩余账号，返回已取得结果并标记未完成范围。所有调用者都离开时取消该共享查询；取消一个页面不会影响仍在等待同一结果的其他页面。

流量和费用的报告缓存也存入 SQLite：最多 32 份、有效报告内容合计最多 16 MiB、单份最多 4 MiB。重启后仅复用未过期且账号版本、范围和查询参数匹配的结果，读取不会延长原有效期。过期、损坏或存储不可用时回到正常 OCI 查询；新鲜结果不会因缓存保存失败而丢失。缓存仅存公开报告字段，不存 API 私钥或登录凭据。CPU 的短期缓存仍在内存中。

## 流量统计

按账号、区域、实例、网卡和日期筛选，展示接收、发送、双向合计、趋势及网卡明细。当前实例清单提供资源归属；已从库存移除的历史网卡不属于该查询范围，页面会明确提示。

- 来源为 `oci_vcn` 的 `VnicFromNetworkBytes`（接收）和 `VnicToNetworkBytes`（发送）。统计包含内网通信，不能直接用于公网计费；同一网卡的多个 IP 无法独立拆分。
- 使用 `1h.sum()` 并令 `resolution=1h`，读取完整小时，再按需要汇总为 UTC 日。API 时间戳表示窗口结束，返回给页面的时间表示窗口开始。东京和新加坡的真实数据已用 5 分钟桶对照验证这一映射。
- 当前尚未结束的小时不计入；`dataThrough` 标明统计截止。小时和日统计使用同一批不重叠数据，避免重复累计。
- 缺失采样保留为 `null`。部分网卡不可读或部分时间缺失时，卡片与趋势显示已观测小计，时间桶明确标为部分数据；整个桶都没有采样时仍为空，图表不跨缺口连线，不把缺失伪造为零。接口完整性描述不等同于原始分钟数据全部齐全或历史网卡完整。
- 保留原始字节值，界面使用 GiB。查询限制在最近 90 个 UTC 日内，正常结果缓存 5 分钟，部分结果短暂缓存以便重试。

## 成本分析

按租户查询 Usage API 的 `COST`，以币种、服务、区域和资源 ID 分组。结果包含当前库存外的费用项目；能关联到实例、启动卷或网卡时补充名称，不将其余收费项丢弃。

- 日粒度最多 90 日；月粒度选择最多 12 个已结束的完整月份。UI 日期包含首尾日，接口转换为 UTC 起点包含、终点不包含的区间。
- 始终读取完整分页。遇到重复分页标记、数据上限或无效记录时标记不完整，不能以部分数据生成完整总额。
- 金额按十进制字符串精确汇总，不同币种分开展示。缺失金额、缺失币种、空数组、确认零费用及账号读取失败各自保留语义，不默认 USD，不把未知金额补成零。SDK 若已经把原始 JSON 数字解码为浮点数，无法反向恢复丢失的源精度。
- 同一租户通过多个账号接入时避免重复累计费用。服务接入区域采用账号已保存的配置区域，费用行的 `region` 是数据维度，两者不混用。
- OCI 费用可能延迟最多 48 小时，最新记录仍可能调整。正常结果缓存 1 小时；服务/区域筛选后的界面金额明确标注为已获取小计。
- 读取成本通常需要 `read usage-report in tenancy` 等权限；只有用量读取权限不保证能读取金额。错误仅返回经过处理的信息，不返回凭据或 SDK 原始请求。

## 接口和保护边界

`GET /api/analytics/traffic` 与 `GET /api/analytics/costs` 返回报告；同路径 `POST` 使用相同查询参数进行手动刷新。均要求登录，POST 还要求同源。演示模式返回明确标注的示例数据，不读取真实账号或调用 OCI。

查询参数只接受规定字段，不接收任意 MQL、租户 ID 或凭据。流量实例和网卡必须属于所选账号的库存及当前启用区域，旧库存不能扩大查询范围。读取前后检查账号配置版本，避免账号被替换或删除后发布旧查询结果。短期缓存不包含私钥，按账号版本和查询范围隔离，并限制条目数及总内存；单实例指标同样在命中缓存前验证当前账号与区域。

每类读取设有整体时间预算、分页或范围上限，并限制并发；查询失败时保留当前已显示数据。详情和测试证据见 [验证记录](VERIFICATION.md)。
