## 变更

- 默认访问端口调整为 `6240`，Docker Compose 端口映射为 `127.0.0.1:6240:3000`。
- 移除 `.env.example`、Compose 环境变量插值和 Worker 的环境文件加载参数。端口及数据目录直接在 Compose 中配置。
- 登录页、侧栏和 favicon 统一使用 Oracle 椭圆环标识，素材随应用提供。
- 修正登录页品牌文字在深色主题下的对比度，并更新浏览器测试的静态资源白名单。

## 升级

升级前备份完整数据目录，并保留现有端口和反向代理配置。

- 保留原 `3000` 端口：将 Compose 映射改为 `127.0.0.1:3000:3000`。
- 使用新 `6240` 端口：同步调整反向代理上游和 SSH 隧道。
- 旧 `.env` 中的 `PORT` 不再控制宿主端口。若旧部署仍依赖环境变量中的 `MASTER_KEY`，先完成密钥迁移，再归档环境文件。
- 数据仍保存在 `./data`，升级不会自动搬迁数据或重置管理员。旧命名卷部署须先按文档迁移。

本版本提供 `linux/amd64`、`linux/arm64` 镜像及独立的 `compose.yaml` 附件。
