## 变更

- 账号默认使用 OCI 租户名称，替代从 API 私钥文件名推断名称的方式。名称在后台连接验证成功后更新，添加账号无需额外等待。
- 保留自定义账号名称。编辑同步区域或替换凭据时，未修改的名称继续使用原命名方式。
- 编辑账号时清空名称，可恢复自动命名；读取成功前保留原名称。自动名称同步更新实例与任务中的账号显示。

## 升级

升级前备份完整数据目录，按[升级指南](https://github.com/ZeonXr/oci-dash/blob/main/docs/OPERATIONS.md#恢复与升级)更新镜像。

已有账号名称保持不变。需要改用租户名称时，在“设置 → OCI 账号 → 编辑”中清空账号名称并保存；若账号有未结束的任务，等待任务完成后再操作。无需重新导入配置或上传私钥。

本版本提供 `linux/amd64`、`linux/arm64` 镜像及固定版本的 `compose.yaml` 附件。仓库默认 Compose 继续使用 `latest`。
