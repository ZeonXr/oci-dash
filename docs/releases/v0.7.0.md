## 变更

- 界面统一使用 shadcn/ui 基础组件，调整按钮、下拉选择、弹窗、菜单和提示的外观与键盘交互，统一浅色和深色主题。
- 改进实例、账号、任务及统计页面的筛选、详情和表格布局。实例详情与设置使用线条式标签导航；弹窗固定标题与操作区，内容独立滚动，改善窄屏和短屏下的使用体验。
- 统一刷新按钮、等待动画和更新时间提示。按钮等待状态覆盖实际手动刷新过程，后台轮询不触发按钮动画；图表统一图例、提示和颜色，修复窄屏统计筛选控件重叠。
- Web、业务 API、后台任务和控制台改为在同一个 Node.js 应用进程中运行，共享数据库连接和缓存，统一就绪检查与停止流程。后台任务仍保留持久队列、资源锁和检查点恢复。
- 新增恢复数据的只读离线核验命令 `node dist/check-data.mjs`，检查数据库完整性、主密钥配对及账号和 MFA 密文解密，不启动后台任务或访问 OCI。
- Node.js 更新至安全补丁版本 `26.13.1`，构建使用 npm `12.2.2`，运行镜像移除 npm 和 npx。源码开发增加通用 VS Code 启动配置，无需安装 mise。

## 修复

- 修复未填写安全规则说明时，向 OCI 发送空描述导致新增失败的问题。新规则省略空描述，已有失败任务重试时也会处理已保存的空描述，保留原规则与并发保护。
- 安全规则任务结束后重新读取规则和 ETag，避免页面保留旧规则或后续提交使用过期状态。
- 修复任务在等待 OCI 完成或重试期间过早释放资源锁的问题，并改进数据库并发初始化的重试。
- 详情弹窗优先聚焦标题，避免打开时自动显示首个复制按钮的提示。

## VNC 控制台

刷新页面后可恢复当前登录会话在该实例最近的失败或关闭记录，连接失败原因不再随页面刷新消失。

实例已有控制台连接时，可查看连接 ID 和状态，并明确确认“结束旧连接并重新创建”。应用重新核验目标后只替换指定连接；该操作会断开旧控制台客户端，不会重启实例。未确认时保留已有连接，自动清理仍只处理本应用拥有的会话。

VNC 通道需要 Linux 容器运行，镜像已包含 OpenSSH。Windows 原生 Node.js 仍可用于界面和业务 API 开发；尝试创建 VNC 会话时会明确提示平台限制。

真实 OCI 验收已在 Linux `amd64` 容器中覆盖画面连接、断开清理、应用重启恢复和明确确认后的旧连接替换，范围与限制见[验证记录](https://github.com/ZeonXr/oci-dash/blob/main/docs/VERIFICATION.md#真实-oci-vnc-验收)。

## 升级

数据库结构和迁移文件、Compose 配置均未变化。使用 v0.6.1 的数据目录可继续升级，无需重新创建管理员或导入 OCI 账号。升级前结束活动任务和控制台会话，备份包含 `.master-key` 的完整数据目录，再按[更新说明](https://github.com/ZeonXr/oci-dash/blob/main/docs/OPERATIONS.md#恢复与升级)更新镜像。

默认端口仍为 `6240`，容器内端口为 `3000`，数据挂载仍为 `./data:/data`。无需增加 Worker 服务或环境配置。

源码运行要求 Node.js `>=26.13.1 <27`。开发使用 `npm run dev`，生产构建后使用 `npm start`；两者均启动完整应用，不再单独运行 `npm run worker`。自定义部署若覆盖了启动命令，应改用 `node dist/runtime.mjs`。备份与恢复步骤见[运维说明](https://github.com/ZeonXr/oci-dash/blob/main/docs/OPERATIONS.md#备份)，恢复数据时使用新的离线核验命令。

发布流程为 `linux/amd64`、`linux/arm64` 构建镜像，并生成固定版本的 `compose.yaml` 附件；通过发布验证后才更新 `latest`。
