## 变更

- 引入 Drizzle ORM，账号、资源、登录会话、控制台和统计缓存使用类型化查询，共享现有 SQLite 连接与事务。
- 表结构统一由 TypeScript schema 定义，使用 Drizzle Kit 生成 SQL，启动时通过官方 migrator 自动初始化。
- 移除分散的建表、补列和历史回填逻辑。任务领取与租约继续保留明确的 SQL 和事务边界。
- Compose 配置保持不变，无需额外数据库服务或手动初始化命令。

## 部署

本版本面向全新部署，需要独立的空数据目录，不提供旧数据库的转换或兼容路径。已有部署应保留原数据与对应版本镜像；测试本版本时使用新的部署目录，不覆盖原数据。

本版本提供 `linux/amd64`、`linux/arm64` 镜像及固定版本的 `compose.yaml` 附件。
