# Country flag assets

Selected 4:3 flag SVGs from [lipis/flag-icons](https://github.com/lipis/flag-icons), licensed under the [MIT License](LICENSE).

Source commit: [`ac7e0eb3259eb62aa6100c435607e2fe03896a97`](https://github.com/lipis/flag-icons/tree/ac7e0eb3259eb62aa6100c435607e2fe03896a97/flags/4x3).

Copyright (c) 2013 Panayiotis Lipiridis.

These files are served locally by OCI Dash. The application does not fetch flags from a CDN at runtime. The region-to-country map is maintained explicitly in `src/lib/region-countries.ts`; unknown region IDs have no flag.
